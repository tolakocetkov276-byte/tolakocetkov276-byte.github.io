## Проекты

### Lumo — фотостудия в Telegram

Мини-приложение для обработки фотографий: пресеты, настройка изображения, точечная ретушь и увеличение для работы с деталями.

[Открыть Lumo](https://t.me/LumoPhotoAppBot)

### КОНТУР — сайт барбершопа

Учебный сайт вымышленного барбершопа: описание услуг, светлая и тёмная темы, пошаговый выбор услуги, мастера и времени. Запись демонстрационная — реальные заявки не отправляются.

[Посмотреть КОНТУР](https://tolakocetkov276-byte.github.io/kontur.html)

### Журнал обслуживания техники

Веб-приложение на **Python, Flask и SQLite** для учёта погрузчиков, моточасов, планового ТО, ремонтов и расходов. Есть поиск, список ближайших обслуживаний и история работ.

Публичная учебная версия работает без регистрации: все посетители видят общие записи и могут их изменять. Для знакомства с приложением используйте вымышленные данные.

[Попробовать приложение](https://tolakocetkov276.pythonanywhere.com) · [Посмотреть код](https://github.com/tolakocetkov276-byte/service-journal)
